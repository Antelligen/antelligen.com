# antelligen.com

One screen: the line, the two ways in (GitHub, e-mail) and the film. Static files, no framework and no build step;
the typefaces are served from this folder.

```sh
python3 -m http.server 4321    # then open http://localhost:4321
```

```
index.html      the page
terms.html      terms of service
privacy.html    privacy policy
404.html        not found
assets/css      site.css
assets/js       site.js: the bar, and the film that plays while it is in sight
assets/fonts    Geist, Newsreader (the app's own faces)
assets/img      the mark, the icons, the social card, the film's poster
assets/video    the film at 1080p and 720p
CNAME           antelligen.com
```
